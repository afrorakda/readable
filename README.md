# READABLE | Fridge Combo #114

A minimalist visual clarity and accessibility checker. It instantly determines whether black or white text is more legible on a chosen background and provides real-time color blind simulations.

## Core Philosophy
- **1 Tool / 1 Action**: Focuses entirely on text legibility and color accessibility.
- **Decision, Not Data**: Instead of complex contrast ratios, it simply tells you "Use this" with a checkmark.
- **Inclusive Design**: Built-in color blind previews ensure your design is readable by everyone, regardless of their color perception.

## Features
- **Smart Contrast Detection**: Analyzes the background luminance and recommends the optimal text color (Black vs. White).
- **Triple Simulation**: Real-time previews for major color vision deficiencies:
    - **P-type (Protanopia)**: Red-blind.
    - **D-type (Deuteranopia)**: Green-blind.
    - **T-type (Tritanopia)**: Blue-blind.
- **Flexible Input**: Supports HEX codes with or without the "#" prefix, as well as 3-digit shorthand.
- **Instant Copy**: Tap the main preview board to copy the valid HEX code to your clipboard instantly.

## Usage
1. Paste or type a HEX color code (e.g., `#007AFF` or `FF8648`) into the input field.
2. The board immediately updates to show the recommended text color with a ✅.
3. Check the **Color Blind Preview** section to ensure the text remains legible across different vision types.
4. Tap the preview board to copy the final color for use in your design tool or code.

## Privacy & Performance
- **Browser Only**: All calculations and simulations are performed locally in your browser.
- **Ultra-Fast**: No images or heavy libraries; uses pure mathematical color transformation for instant results.
- **Zero Tracking**: No data ever leaves your device.
